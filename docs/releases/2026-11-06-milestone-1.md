# Milestone 1 release — Vercel hardening and Next.js adoption

Date: 2026-11-06

## Delivered

- Node 24 is the single runtime across Vercel, Docker and GitHub Actions.
- The runtime audit is clean: `@vercel/cli-config` is pinned to 0.3.7 through an
  npm override.
- Production migrations run under a PostgreSQL advisory lock, log the applied
  count and fail the build before traffic is assigned.
- Preview deployments use a separate Prisma Postgres resource and Preview-scoped
  `DATABASE_URL*` values.
- Non-secret Vercel variables are Config values; `BLOB_READ_WRITE_TOKEN` is gone
  from Production and Preview, and profile uploads use OIDC.
- GitHub auto-deploy is connected: branch pushes create Preview deployments and
  `main` creates Production deployments.
- The assistant has per-response and per-run output ceilings, a request timeout,
  Gateway user/persona/environment tags, abort/timeout run states and an approval
  flow covered end to end.
- Instant Navigation has a production-build baseline for the public pages, the
  dashboard and assistant conversations.
- Every dashboard route streams through `src/app/dashboard/loading.tsx`; the
  assistant and auth pages have Suspense frames. The root locale strategy is
  recorded in ADR-0031.
- Dependabot, a weekly runtime audit and a documented review policy are in
  place.

## Production notes

- The AI Gateway free tier does not include `openai/gpt-5.4`. Production uses
  `nvidia/nemotron-3.5-lightning-free` until credits are added; set
  `ASSISTANT_MODEL` to the paid model when the team upgrades.
- Vercel commit-signature enforcement was disabled because the repository does
  not sign commits. Re-enable it after configuring SSH or GPG signing for every
  contributor.
